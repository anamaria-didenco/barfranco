# How to edit the Bar Franco website

Open **www.barfranco.nz/admin/** (or `/savoy/admin/` while the new site is in preview). Everything happens in your browser. Nothing goes live until you press **Save & publish**.

## The first time: get a key

The editor saves straight into the website's GitHub account, so it needs a key that lets it write there. You make the key once:

1. Sign in to **github.com**, click your picture (top right) → **Settings**.
2. Bottom of the left menu: **Developer settings** → **Personal access tokens** → **Fine-grained tokens** → **Generate new token**.
3. Name it *Website editor*. Set the expiry as far out as it allows.
4. **Repository access**: choose *Only select repositories* and tick **barfranco**.
5. **Permissions → Repository permissions**: set **Contents** to *Read and write*. Leave everything else alone.
6. **Generate token**, copy it, paste it into the editor's sign-in box.

The key stays in that browser only. On another computer or phone you paste it again. If you ever lose it, make a new one the same way.

## Editing

- **Pages** are listed on the left. Click one to open it.
- **Words**: click any words on the page and type. Press **Escape** when you are done. Shift+Enter makes a new line.
- **Photographs**: click any photograph. On the right, **Choose a photo** opens everything already on the site, **Upload** adds one of your own (it is shrunk to web size for you). Fill in the one-line description under it: that is what Google and screen readers see.
- **Buttons and links**: click the words on a button and the link it goes to appears on the right.
- **Title and description in Google**: at the top right of every page. Keep the title under about 60 letters and the description under about 155.
- **Big words** (the large headings in the middle of a page): click them and type into the box on the right.
- **Colours & fonts** (bottom left): the three brand colours and the fonts for headings and text, for the whole site. **Back to the brand colours** undoes experiments. You can add a font file and pick it from the lists.
- **Phone**: the Phone button at the top shows the page as a phone sees it.

## Saving

**Save & publish** lists what changed, then **Publish** sends it. The live site shows the change about a minute later (refresh the page). If the editor says the site changed while you were editing, reload the editor and do the edit again.

## Undo

**History** (bottom left) lists every save. **Undo** on a line puts the site back as it was before that save. An undo is itself a save, so it can be undone too.

## If something looks wrong

- A dotted outline means "you can type here". It is never on the live site.
- Scripts are switched off inside the editor, so the slideshow does not move and the enquiry form shows as a plain box. They work on the live site.
- Close the tab without saving and nothing has changed.
